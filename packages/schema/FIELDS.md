# AI Usage Event — Field Reference & Privacy Justification

Feeds the DPIA pack. One row per field: what it is, why we collect it, and the privacy control applied. Guiding rule per locked decision: **metadata only — no prompt text, no response text, no file contents, no code.** The JSON Schema enforces this with `additionalProperties: false`.

## Design decisions worth recording

- **`match_flags` is required, not optional.** An empty array is an explicit statement ("detectors ran, nothing fired"), distinguishable from "no detection ran". This matters for audit: absence of a flag must never be ambiguous.
- **`enforcement_posture` applies that same rule to enforcement (v1.7).** `enforcement` shipped in v1.5 as a decision-only record, which reintroduced exactly the ambiguity `match_flags` was designed to avoid one level up: an endpoint that never ran the rules and an endpoint that ran them cleanly both emitted nothing. The first shadow-bake report duly printed a zero it could not have printed anything else for. The posture marker is the "detectors ran" statement for enforcement — emitted on every event, decision or not — and the bake report treats its absence as no coverage rather than as a clean result.
- **Endpoint events must carry `model`** (conditional requirement in schema). If an endpoint collector can't see the model, that's a collector bug we want to surface, not silently accept. Proxy events legitimately can't observe it → nullable.
- **Rejection, not scrubbing, at ingest.** Events with out-of-schema fields (e.g. a misbehaving collector attaching `prompt_text`) are rejected whole, counted, and alerted. We do not "clean and store" — that would mean content transited the platform.
- **Pseudonymization is HMAC-SHA256 with a company-held salt.** Plain SHA-256 of emails is dictionary-attackable over a 700-person org; the HMAC salt makes the mapping non-recomputable without KMS access. Salt rotation is a major-version event (see VERSIONING.md).
- **No per-employee surveillance fields by design.** No screenshots, no keystrokes, no prompt content, no file names. The minimum that answers "who (team) uses which AI tools, how much, against which repos, with what risk signals."
