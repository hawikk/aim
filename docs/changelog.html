0.1.5 - 2026-09-11

aim mcp (AIM-1213) and named Audit/Enforce who-scope (AIM-1217). Public docs match the live enforcement capability matrix. Prepared in git; PyPI publishes when v0.1.5 is tagged.

  • aim mcp: stdio MCP server plus Agent Plugins 1.0. Metadata-only inventory. Zero outbound. Personal and plugin modes never actuate.
  • Audit/Enforce with named who-scope: user, install, or confirmed fleet. Empty named lists are not fleet.
  • Public README and architecture match the live enforcement capability matrix (Claude-only leftovers removed).
  • Public Community copy: free and uncapped. Hosted Cloud is 3 agents free, then $2 / agent / month. Copy only: see pricing.
  • Public landing and docs pages use ASCII punctuation instead of em or en dashes.

0.1.4 - 2026-08-18

Public Community snapshot under Apache-2.0. Endpoint blocking where vendor hooks exist. Tag message: endpoint blocking for Cursor, Copilot, Kimi, Grok.

  • Cursor, GitHub Copilot, Kimi Code, and Grok Build can actuate on the endpoint when a managed enforcement.json is loaded. Grok denies tool calls only. Copilot CLI does not block the initial prompt.
  • Public Community snapshot of the working tree on hawikk/aim.
  • Published wheel license: Proprietary (0.1.1-0.1.3) → Apache-2.0 (0.1.4).
