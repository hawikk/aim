Self-host demo

Full stack on a laptop: collectors, ingest, Postgres, dashboard. Target time-to-green is about 30 minutes with Docker installed.

git clone https://github.com/hawikk/aim.git
cd aim
./scripts/demo-stack-up.sh
# → http://127.0.0.1:8081

This is a loopback eval with a demo seed. It is not personal mode (that is aim personal, no Docker) and not a production HA guide.

What you get

  • Dashboard at http://127.0.0.1:8081 (personal/standalone local admin, no SSO)
  • Ingest on :8080, Postgres on loopback, optional Gatehouse
  • A deterministic 12-seat demo cohort so the UI is not empty

Prereqs

Docker Engine + Compose v2, Python 3.11+ (for local secret minting), ~8 GB RAM, ~10 GB disk, free ports 8080/8081/5432.

Happy path, failure modes (missing Docker, port conflicts), and non-goals: self-host quickstart.

This public snapshot does not publish container images, so the GHCR pull path in prebuilt-images.md will not resolve. install-pilot.sh falls back to building from source.
